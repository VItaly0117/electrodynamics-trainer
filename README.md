# Тренажер електродинаміки

Картки до усного іспиту (431 питання з відповідями й формулами) та інтерактивні рисунки з СТВ, оптики, скін-ефекту, диполя й феромагнетика.

- `index.html` — сайт (JS без збірки, формули через MathJax з CDN)
- `cards.json` — питання й відповіді
- `answers.pdf` — ті самі відповіді одним PDF
